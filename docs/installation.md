# Installation

Install the latest release from PyPI:

```bash
pip install bns_remnant_classifier
```

The package requires Python 3.12 or later. Its dependencies (`numpy`,
`scipy`, `pandas`, `joblib`, `scikit-learn`, `bilby`, `astropy`, `tqdm`) are
installed automatically.

## Development install

To work on the package itself, clone the repository and install it in
editable mode:

```bash
git clone https://github.com/AnnaPuecher/bns_remnant_classifier
cd bns_remnant_classifier
pip install -e .
```
