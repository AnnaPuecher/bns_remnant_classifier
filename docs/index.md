# bns_remnant_classifier

Python package to run ClassifierA and ClassifierB from
*Phys. Rev. D 110 (2024) 12, 123038*. The classifiers take as input the
parameters of a BNS system and predict the remnant formed after the merger.
Application possible both to parameters posterior samples and low-latency
point estimates. Marginalizes over equation of state when tidal information
is not available.
